## ✦ 当前主线

### 🌌 天空岛体系 · SkyIslandSystem

Paper 1.20.1 服务器维护插件，连接独立 OpenClaw 实例，设定五位治理角色：

| 角色 | 权能 | 状态 |
| :---: | :--- | :---: |
| **天理－法涅斯** | 全局规划与四影审批 | `最高治理` |
| **死之执政－若娜瓦** | 死亡、实体过载、灾难风险 | `调查中` |
| **生之执政－纳贝里士** | 生物生态与生成压力 | `观察中` |
| **时之执政－伊斯塔露** | TPS、时间线与备份状态 | `巡查中` |
| **空之执政－阿斯莫代** | 维度、区块、边界与传送 | `守望中` |
